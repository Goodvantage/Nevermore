# Implementation and release boundaries

This is the implementation inventory, not a claim that the release gates have passed.

| Area | Local implementation | Validation required before release |
| --- | --- | --- |
| Native shell | Tahoe split-view window with glass sidebar, thread inspector and floating Liquid Glass composer; customizable toolbar (new message, collections, conversation menu, search; back/forward is an optional item); Mail-style menus with Go, Conversation and Message menus and validated titles/check marks; window tabs with restored tab groups; sheets for prompts; native Outbox table; tabbed Settings; hover actions and contextual menus; type-to-compose; native text responder chain, searchable conversation/person chooser, favorites, per-window navigation, frame/workspace/anchor/thread restoration, application-targeted New Message/Dock commands, optional menu bar item with a choice of icons, opt-in login registration, spelling/substitutions, native keyboard help and redacted diagnostics | VoiceOver/keyboard/IME matrix, real multi-account use |
| Themes | Sixteen themes from Settings ▸ Appearance or View ▸ Theme: Classic (the unchanged system look) plus Memphis, Halloween, Neon Fun, Bubblegum, Nevermore, Synthwave, Vaporwave, Under the Sea, Meadow, Cosmic Sprinkles, Aurora, Lemonade, Peppermint, Midnight Cocoa and Phosphor. Each forces light or dark, colors the transcript (per-author name colors, links, alerts, selection), tints the sidebar and composer glass, sets display/body faces, and draws a static wallpaper of motifs and ornaments with a one-shot celebration on switching. Unit-tested WCAG contrast audit over every preset's palette and wallpaper; wallpaper off under Increase Contrast, celebrations off under Reduce Motion. The themes are presets: Customize Theme (Settings ▸ Appearance or View ▸ Theme) edits the active one's appearance, colors, gradient, sidebar and composer tints, name colors and glow, wallpaper motifs and ornaments, fonts, celebration and empty-window art and title, live in every window, with a low-contrast warning and Reset to Preset; changes are kept per preset. One backdrop opacity slider fades every theme's gradient, wallpaper and sidebar tint toward the plain background | Real-desktop Liquid Glass tint legibility, VoiceOver pass over the gallery and the theme editor, scroll performance with wallpaper on reference hardware, the editor's color panel and live edits on a real desktop |
| Accounts | Dedicated-client browser PKCE, isolated Keychain and stores, refresh/revocation and account removal | Real Frappe 15/16 SSO/MFA/public-client registrations |
| Reading | Safe rich HTML codec, continuous selectable transcript, grouped sender headers with avatars (profile photos from the site, initials otherwise), time-only headers under day dividers with full timestamps in copies, centered system events, bot attribution, reaction chips and reply quotes, message rotor/keyboard navigation with guarded accessibility actions, native plain/RTF copying without presentation controls, bounded native tables with spans and complete text fallback, pane-width wrapping, bounded cached history, known-watermark unread divider, accessible new-message/Jump to Latest control with stable reading anchors, older pages/context requests, adjustable text size/spacing, bounded input bytes, collapsible long code and a native unwrapped code reader with exact Copy Code | Real cross-client corpus, history boundary batches, table accessibility, performance |

| Attachments | Finder/paste and file-promise receiving in Visual and Markdown composers, 20 MB clipboard-image limit with feedback, private descriptor-based snapshots, cancellable account-bound staging, private upload, bounded authenticated streaming downloads, quarantined atomic export, native Quick Look/Save As, saved-file sharing/Open With and outbound file promises. | Performance | Isolated Release measurement command, bounded parsed-document cache/history/visible rows, persisted cached launches, production Send-action feedback and synthetic click totals, p50/p95 switch/scroll/store samples, idle CPU/RSS/footprint and UUID-owned cleanup | Reference hardware/server behavior, multi-account growth, display-frame cadence and energy remain evidence gates |
| Distribution | Sandboxed signed bundle, universal build option, Sparkle with configured pinned public key, notarization/DMG scripts | Actual production signing/notarization, complete signed-update round trip |

The plan explicitly makes native Share extension delivery conditional on lifecycle/security tests. That extension, APNs provider integration, native calls, specialized AI/admin UI, Spotlight and App Intents remain deferred. Archive/mute contracts are now source-verified and have native controls; their deployment permission/transition matrix remains open. Linked documents have native permission-filtered previews, browser handoff and server-returned workflow transitions with explicit confirmation. Custom message actions requiring dynamic server forms retain browser handoff.

Do not call this a validated 1.0 release on the strength of unit tests or a local demo. Use the [validation record](VALIDATION.md) and the plan's release checklist.
