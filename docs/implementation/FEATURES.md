# Implementation and release boundaries

This is the implementation inventory, not a claim that the release gates have passed.

| Area | Local implementation | Validation required before release |
| --- | --- | --- |
| Native shell | Tahoe split-view window with glass sidebar, thread inspector and floating Liquid Glass composer; customizable toolbar (new message, collections, conversation menu, search; back/forward is an optional item); Mail-style menus with Go, Conversation and Message menus and validated titles/check marks; window tabs with restored tab groups; sheets for prompts; native Outbox table; tabbed Settings; hover actions and contextual menus; type-to-compose; native text responder chain, searchable conversation/person chooser, favorites, per-window navigation, frame/workspace/anchor/thread restoration, application-targeted New Message/Dock commands, optional menu bar item with a choice of icons, opt-in login registration, spelling/substitutions, native keyboard help and redacted diagnostics | VoiceOver/keyboard/IME matrix, real multi-account use |
| Home | Shown whenever no conversation is open, from the sidebar's Home row or Go ▸ Home (⇧⌘H): favorites as tiles with unread badges, Unread with the newest message from the channel list (muted conversations as one quiet line, archived ones left out, Mark All Read up to the listed message), Later (reminders, saved messages, drafts, unsent messages), People You Talk With Most, Your Week, Threads You Follow and Recent Files. Customize Home shows, hides and reorders modules; one or two columns follow the window width. Showing Home marks nothing read; the same words appear in every theme | Raven sites without `get_unread_threads`, `most_used_reactions` or list access to `Raven Message`; search index lag for Recent Files; very heavy senders past the 5,000-message page |
| Themes | Sixteen themes from Settings ▸ Appearance or View ▸ Theme: Classic (the unchanged system look) plus Memphis, Halloween, Neon Fun, Bubblegum, Nevermore, Synthwave, Vaporwave, Under the Sea, Meadow, Cosmic Sprinkles, Aurora, Lemonade, Peppermint, Midnight Cocoa and Phosphor. Each forces light or dark, colors the transcript (per-author name colors, links, alerts, selection), tints the sidebar and composer glass, sets display/body faces, and draws a static wallpaper of motifs and ornaments with a one-shot celebration on switching. Unit-tested WCAG contrast audit over every preset's palette and wallpaper; wallpaper off under Increase Contrast, celebrations off under Reduce Motion. The themes are presets: Customize Theme (Settings ▸ Appearance or View ▸ Theme) edits the active one's appearance, colors, gradient, sidebar and composer tints, name colors and glow, wallpaper motifs and ornaments, fonts and celebration, live in every window, with a low-contrast warning and Reset to Preset; changes are kept per preset. | Realtime | Socket.IO account namespace/rooms, invalidation and canonical refresh, catch-up on activation and window focus, 15-second disconnected fallback for open conversations | Proxies, Frappe 15/16 differences, sleep/auth transitions and permission changes; socket connection alone does not establish room delivery |

| Search | A results screen in the window's conversation pane (`docs/design/search/SEARCH-RESULTS.md`): the toolbar field searches as you type after a pause, Return searches at once, and ⌥⌘F/⇧⌘F focus it. | Preferences/presence | Account-scoped availability/status/read-receipt/after-hours settings, local site-timezone quiet hours, conservative foreground activity heartbeats | Real cross-device behavior and older/missing server fields |
| Localization | Bundled typed connection/outbox/error keys, partial German lookup/format resources with English fallback, precise site-timezone timestamp parsing and regional display refresh | English remains the supported UI language; complete language/RTL/VoiceOver matrix |
| Performance | Isolated Release measurement command, bounded parsed-document cache/history/visible rows, persisted cached launches, production Send-action feedback and synthetic click totals, p50/p95 switch/scroll/store samples, idle CPU/RSS/footprint and UUID-owned cleanup | Reference hardware/server behavior, multi-account growth, display-frame cadence and energy remain evidence gates |
| Distribution | Sandboxed signed bundle, universal build option, Sparkle with configured pinned public key, notarization/DMG scripts | Actual production signing/notarization, complete signed-update round trip |

The plan explicitly makes native Share extension delivery conditional on lifecycle/security tests. That extension, APNs provider integration, native calls, specialized AI/admin UI, Spotlight and App Intents remain deferred. Archive/mute contracts are now source-verified and have native controls; their deployment permission/transition matrix remains open. Linked documents have native permission-filtered previews, browser handoff and server-returned workflow transitions with explicit confirmation. Custom message actions requiring dynamic server forms retain browser handoff.

Do not call this a validated 1.0 release on the strength of unit tests or a local demo. Use the [validation record](VALIDATION.md) and the plan's release checklist.
